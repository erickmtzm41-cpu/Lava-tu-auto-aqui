# Política de seguridad

## Alcance

Este repositorio contiene un sitio web estático para la promoción y cotización de servicios de lavado de autos. Agradecemos los reportes responsables de vulnerabilidades en el sitio, sus scripts y la automatización del repositorio.

## Reportar una vulnerabilidad

Utiliza un reporte privado de vulnerabilidades de GitHub:

https://github.com/erickmtzm41-cpu/Lava-tu-auto-aqui/security/advisories/new

No publiques detalles de una vulnerabilidad en issues, pull requests, chats públicos ni redes sociales antes de que haya sido evaluada y corregida. Incluye, si puedes:

- Una descripción del problema y su impacto potencial.
- Pasos de reproducción y evidencia que no exponga datos personales ni secretos.
- URL, commit o versión afectados, y navegador o entorno relevante.
- Una sugerencia de mitigación, si la tienes.

No realices pruebas que afecten a terceros, interrumpan el servicio o accedan a información que no te pertenece.

## Qué esperar

- Procuraremos confirmar la recepción dentro de cinco días hábiles.
- Revisaremos la reproducibilidad, el impacto y la severidad, y podremos solicitar información adicional.
- Si el reporte es válido, coordinaremos una corrección y una divulgación responsable; no divulgaremos información sensible antes de que exista una mitigación razonable.
- Si no se confirma o queda fuera del alcance, explicaremos el motivo y, cuando sea posible, indicaremos próximos pasos.

Los tiempos de resolución dependen de la severidad, el alcance y la disponibilidad de una solución segura.

## Versiones

La versión mantenida es la publicada desde la rama principal del repositorio. Se priorizarán las correcciones de seguridad para esa versión; no se garantiza soporte para versiones antiguas o forks.

## Áreas de interés

Código del sitio (HTML, CSS y JavaScript), entradas de usuario y generación de cotizaciones, enlaces y recursos externos, dependencias, secretos, permisos y flujos de GitHub Actions.
